    タスクボード 使い方ガイド

    計画のメンテが面倒すぎたので、ボードにしました。

    つくったひと より ／ 読む時間 約5分

    Redmine でチケットを探して、開いて、進捗を選んで、保存して……。正直、これが毎日の地味なストレスでした。
    「計画を守る」より「計画を直す」ほうに時間を取られていた気がします。
    なので、見る・動かす・終わらせるをワンクリックでできるボードを作りました。中身は今までどおり Redmine です。

    01なぜボードにしたのか

    Redmine は記録としては優秀です。ただ、日々の更新がとにかく面倒でした。

    これまで
    • 自分のチケットを検索して一覧を出す
    • 1件ずつ開いて進捗をプルダウンで選ぶ
    • 親チケットの進捗も手で合わせる
    • 月末に工数を思い出しながら入力
    • 誰が忙しいかは聞いてみないと分からない
    これから
    • 開けば自分の仕事が優先順に並んでいる
    • 進捗はボタンをポンと押すだけ
    • 親チケットは子に合わせて自動で更新
    • 工数は進捗を押したついでに1クリック
    • 「全体」タブでチームの状況が一目で分かる

    ボードで動かした内容は、その場で Redmine に書き込まれます。ボード専用のデータはないので、Redmine 側で見ても同じです。

    02毎日の使い方（ここだけ読めばOK）

    開くと自分のタブが選ばれた状態で始まります。列は左から右へ流れます。

    未着手これから
    進行中0〜80%
    担当完了自分の作業は終わり
    上司完了確認したら上司が移動
    1. 始めたら カードを「進行中」へドラッグ。
    2. 進んだら カード下の 0 20 40 60 80 を押す。
    3. 終わったら 「担当完了」へドラッグ。あとは上司が確認して「上司完了」に動かします。
    4. やらなくなったら ドラッグ中に下に出る「中止」の帯へ落とす。チケットは消えません。

    カードをクリックすると、件名・締切・担当・説明を直せます。コメントを書けば Redmine の履歴にも残ります。

    やる順番は、上下に並べ替えるだけ

    「未着手」「進行中」の列の中でカードを上下にドラッグすると、その順番で日程が決まります。上から順に、予定工数の分だけ詰めて、開始日と作業完了予定を Redmine に入れます（進行中 → 未着手の順）。

    課題バラシでつないだ「前の仕事」がまだ終わっていなければ、その後ろにずれます。並べた順番は次に開いたときもそのまま。間違えたら「元に戻す」で戻せます。

    上の「並び」を 余裕が少ない順 にすると、危ないものから並びます。余裕は「締切までの営業日数 − 残りの作業日数（予定工数と進捗から）」。締切が先でも残りが多ければ上に来ます。緊急（01_市場問題 など）は常にいちばん上。カードに「余裕 2日」のように出ます。この順番で日程を決める を押せば、その順番がそのまま作業順になります。

    フロントバンパー設計 › 補強構造の検討
    ビーム断面の強度解析
    締切 2日超過　予定 10/20

    カードの上の小さい文字は親・親の親です。「何のための作業か」が分かるようにしています。右上の色付きタグはバージョン（仕事の区分）です。

    ★ 優先してほしい

    カードの右上の ☆ を押すと ★ 優先 になります（Redmine の優先度が「高め」に）。「余裕が少ない順」では緊急の次に並びます。上司から「これ先にお願い」と頼むときにも使えます。

    毎週・毎月の仕事（繰り返し）

    週報や月次の集計など、毎回同じ仕事は、編集画面の 繰り返し で「毎週」か「毎月」を選んでおきます。カードに ↻毎週 と出て、担当完了にすると次回分が自動でできます（締切・作業完了予定も 1 週・1 か月先）。遅れて完了したときは、締切が今日より後になるところまで送ります。間違えて作ったときは、お知らせの 取り消す で中止にできます。

    「すでに関連したチケットがあります」と言われたら

    Redmine は 2 つのチケットの間につながりを 1 つしか持てません。「関連している」などが先にあると前後でつなげないので、出てきたお知らせの 外して前後にする を押してください。カードの編集画面の「つながり」で、ボードに出ないつながりも見て外せます。

    休みの予定

    ガントチャートの一番上に入れている「田中半休」のようなマイルストーンを、そのまま休みとして読みます。自分の画面の上に「休み 10/22(木)」、全体タブに「これからの休み」が出ます。1日休みの日は、作業順や課題バラシで日程を決めるときに作業日から外します。同じ名字の人がいるときは「田中太半休」のように名の1文字目まで書いてください。

    詰まりのサイン

    • ⏳ 待ち：前の仕事がまだ終わっていません。待っている相手と仕事の名前が出ます。
    • ✓ 着手できます：前の仕事が全部終わりました。始めどきです。
    • N日動きなし：進捗が5営業日以上動いていません。困っていたら声をかけてください。
    • 進行中が5件を超えると、列の見出しに「上限を超えています」と出ます。広げすぎず、終わらせてから次へ。

    並び順のルール

    バージョン名の先頭の番号が小さいほど上に来ます（01_市場問題 がいちばん急ぎ）。同じ番号なら締切が近い順です。

    03締切と予定のルール

    どこに書く意味
    件名の先頭の 【10/24】本来の締切（お客さん・関係部署との約束）
    Redmine の 期日作業完了予定（自分の見込み）

    締切を過ぎると赤、3日以内だと黄色になります。作業完了予定が締切より後ろだと「予定が締切超え」と出るので、早めに相談してください。

    ポイント：締切と予定の差が「余裕（バッファ）」です。全体ボードでは、この余裕をどれだけ使ったかで、仕事ごとの危なさを見ています。

    04メールで来た仕事の振り分け

    メールから自動で作られたチケット（担当やバージョンが空のもの）は「未整理」タブに集まります。誰が振り分けてもOKです。

    1. 左の一覧からチケットを選ぶ
    2. 締切・件名・バージョン・担当を入れて 整理して登録
    3. 仕事ではないメール（懇親会のお知らせなど）は タスクではない で「中止」に
    4. 大きい仕事は 課題バラシで分解する で、その場で中身に分ける

    05新規タスク・みんなでやる仕事

    右上の ＋ 新規タスク から作れます。バージョンが無ければ、その場で ＋ 新しいバージョン も作れます（「番号_カテゴリ-個別名」の形になります。例：05_開発業務-EV電池ケース）。

    E-ラーニングのように全員がやる仕事は、担当を複数チェックすると人数分のチケットができます。「まとめ用の親チケット」を付けておくと、全体タブの「みんなでやる仕事」で、誰が終わって誰がまだかが分かります。

    06工数入力は「押すだけ」

    これまで月末にカレンダーとメールを見返して、思い出しながら入力。正直つらい。
    これから進捗ボタンを押すと右下に時間が出るので、近いものを1回押すだけ。

    出てくるのは 0.5h 1h 2h 4h 1日 記録しない。押さなければ何も記録されません。

    ほかの人のカードを動かしたときは、担当者の作業時間として記録します（「伊藤さんの今回の作業時間は？」）。手伝った分を自分の時間で入れたいときは、カードの編集画面で 自分（手伝った分） を選んでください。

    右上の 工数 ボタンからは次のことができます。

    • 毎日の実績：前の月の1日から今日までの平日が横に並びます。記録が足りない日は黄、ない日は赤。日付を押すとその日の記録へ。チーム全員も見られます。
    • 日々の記録：その日に動かしたチケットが並ぶので、まとめて入れられます。8時間に届いているかも見えます。
    • 月の集計：バージョン別・人別の合計時間。CSV で保存 して月末の工数入力にそのまま使えます。

    ゆるく行きましょう：きっちり正確じゃなくて大丈夫。月末に思い出すより、ずっと実態に近い数字になります。聞かれたくない人は「接続設定」でオフにできます。

    07課題バラシ

    ガントチャートの「前後のつながり」が見える良さを、もっと手軽に使えるようにした画面です。

    • 中の仕事（子）は親の枠の中に入ります
    • 順番は左から右への矢印。並行できる仕事は縦に並びます
    • 箱の ＋（左・右・下）で前・後・中の仕事を追加
    • 枠のいちばん下の ＋ ここに追加 で、同じ階層に（つながりのない）仕事を追加
    • 足した仕事は、上の仕事（親）の締切を引き継ぎます（名前に【12/1】のように書けばそちら）
    • 箱をドラッグして、相手の左端なら前、右端なら後、真ん中なら中に入れる
    • 予定工数 ＋ で予定時間を入れると、一番長い流れ（順番にしかできない仕事の合計）が赤く出ます

    矢印は Redmine の「先行」として保存されるので、ガントチャートにも同じ矢印が出ます。前の仕事が遅れると、後ろの仕事の日程も Redmine が自動でずらします。

    08日程表（ガント）

    これまでガントは縦に長く、バージョンや親チケットの行で上下に行ったり来たり。締切が出ないので、日付を動かしても間に合うか分からない。
    これからバージョン・親・チケットを横に並べて 1 行 1 チケット。締切は ◆、越えた分は赤。動かしている間に「締切まであと何日」が出ます。
    • 左上で 担当者（1 人ずつ）／チーム全員／バージョン を切り替えます。
    • バーの真ん中をつかんで動かすと移動、端をつかむと開始日・終わりだけ変わります。
    • 後ろにつながっている仕事（課題バラシの矢印）は、重なる分だけ一緒に後ろへずれます。締切を越えても止めませんが、お知らせで教えます。元に戻す で戻せます。
    • 日付のないチケットは、置きたい日を押すと予定工数の長さで置きます。ダブルクリックで編集画面。
    • 前後のつながりは線で結びます。前の仕事が終わる前に始まっているもの（日程が合っていないもの）は赤い線です。「つながりの線」で消せます。
    • 日付を変えても行の並びは変わりません（いじったタスクがどこかへ行かない）。変えた行は黄色になります。並び直したいときは、左上で範囲を選び直してください。

    09全体ボード（朝会・Teams用）

    「全体」タブは、Teams の画面共有でそのまま見せられるように、1画面に収めています。

    • 上の数字：締切超過・今週の締切・2週間で完了した数・見直しが必要な仕事
    • 積み木：いま抱えている仕事の量（多い順）。締切が危ないものは名前が出ます
    • タイムライン：これまでの2週間で終わった数と、これからの2週間の締切の数
    • 仕事ごとの状況：進捗に対して余裕をどれだけ使ったかで「順調・注意・見直し」

    責めるための画面ではありません。早めに助けを出すための画面です。赤いものを見つけたら、遠慮なく声をかけてください（かけます）。

    10困ったとき

    こんなときこうする
    ボードが開かない共有フォルダの kanban_relay.py をダブルクリック。自動で起動してボードが開きます。
    新しい機能が出てこない共有フォルダの kanban_relay.py をダブルクリック（古い版から入れ替わります）。接続設定 の一番下で版を確認できます。
    「更新できませんでした」と出るRedmine 側の権限で止められています。メッセージをそのまま、つくったひとに送ってください。
    表示が古い気がする右上の 再読み込み。Redmine で直接変えた分も取り込みます。
    「上司完了」に動かせない仕様です。担当完了まで動かしてもらえれば、上司が確認して動かします。
    おわりに
    ボードは道具なので、使いにくいところはどんどん直します。「ここが面倒」「こうだったらいいのに」は気軽に言ってください。
    計画を直す時間を減らして、設計に時間を使いましょう。

    11このツールについて

    タスクボードは、Redmine の API（REST API）を使って、業務効率化のために独自に作ったローカルツールです。Redmine の代わりではなく、Redmine のデータを見やすく並べる画面です。

    • どこで動くか：各自の PC の中だけで動きます（中継プログラム kanban_relay.py が、この PC の中でボードの画面を出します）。サーバーの設置や、Redmine 本体への追加・改造はしていません。
    • 通信先：この PC と Redmine の間だけです。ほかのサーバーやクラウドサービスには何も送りません（文字のフォントも PC に入っているものを使います）。
    • できること：表示が中心ですが、ステータス・日付・担当・作業時間・前後のつながりの変更や、チケット・バージョンの作成も、Redmine 標準の API で行います。使う人本人の API キーと権限の範囲で動くので、Redmine 側の権限やワークフローの制限はそのまま効きます。変更は Redmine の履歴にも残ります。
    • API キーの扱い：本人の PC にだけ、Windows の仕組み（DPAPI）で暗号化して保存します。最初に確認した Redmine 以外には送りません。共有フォルダには置きません。
    • 中継する操作：ボードが使う決まった API だけを通し、それ以外は断ります。ほかの Web サイトからは呼び出せません。
